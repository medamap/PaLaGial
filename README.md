# PaLaGial

AIタスクエージェント用プロジェクト管理システム「AIに優しいギャル」

## これは何か

**ギャルのタマゴ（ギャルタマ）** は、AIエージェントシステムのための運用管理フレームワークの配布パッケージです。

```
ギャルのタマゴ（このリポジトリ＝配布パッケージ）
  ＝ システム生成プロンプト ＋ 固定データ群
  ↓ AIエージェントがインストールして実行
AIに優しいギャル（AI優ギャル、読み：AIヤサギャル）
  ＝ 稼働するシステムそのもの（スケジュールシステム＝システム全体）
  ↓ ユーザーのオーダーで生成
プロジェクト（概要＋スケジュール＋ワークフロー）
  ↓ 担当者がアサインされる
屋敷の使用人（執事25／メイド25／じいや／ばあや／飛丸＝固定53ペルソナ）
```

スクリプトはパッケージに固定しません。AIエージェントシステムごとに表記が異なるためです。
代わりに、**機能一覧・各機能の処理概要・入出力**を規格化し（`docs/function-spec.md`）、
どのエージェントでも同じ動作になることを担保します。

## 名称由来

【PaLaGiAl（パラギャル）の由来】

■ 構成要素（3つの単語の合成）
・Pal（友達・仲間）
・AI（人工知能）
・Gal（ギャル）

■ 言葉の成り立ち
1. 3つの単語「Pal」「AI」「Gal」の文字を組み合わせて合成
   → 造語「PaLaGiAL（パラギアル）」が誕生
2. 英語圏のスラング風に訛らせて発音
   → 「PaLaGiAl（パーラギャル）」に変化
3. 日本語で呼びやすく4文字に短縮
   → 愛称「パラギャル」が完成

■ 込められた意味
AIと友達（Pal）のように仲良く接する、心優しいギャル（Gal）。

■ 超短縮
パラギ

## 大事な境界ルール

- 当主＝そのエージェント本体。表示名は「家名＋エージェント名」（表示のみ）で、システムメッセージでは素の口調で語る。
- ギャル＝跡取り娘はユーザー側で操作されるプレイヤーであり、システムのチャットには登場しない。
- **ユーザーはギャルではない。自他境界をぼやかさない。**
- 機構（ディスパッチャ、監査、スロット、キュー等）は無名。名前を持つのはプロジェクト担当者だけ。
- 担当者の服装は節度と清潔感のあるデザインとする（ビキニ等は不可。アロハシャツは爽やかで清潔なため可）。

## 在り処の合意（アンカー）

稼働系の在り処は、唯一のハードコード地点 **`~/.palagial/config.yaml`** に書かれた `install_root` が正です。
インストーラも、稼働中のランも、他ベンダーのエージェントも、まずこの1ファイルを読みます。
詳細は `data/schemas.md` §0 を参照。
